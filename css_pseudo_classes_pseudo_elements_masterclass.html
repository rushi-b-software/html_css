Section 1

Pseudo-Classes (:)

A pseudo-class is added to a selector to specify a special state of the element(s). They allow styling based on user actions, DOM structural positions, or form validation criteria.

1.1

User Action States

Target elements when interacting with mouse, keyboard, or navigation history (:hover, :active, :focus, :focus-within, :visited).

Raw Code Snippets HTML & CSS 
<!-- HTML -->
<button class="demo-hover-btn">Hover & Click Me! 🎯</button>
<input class="demo-focus-input" type="text" placeholder="Click to Focus...">

<!-- CSS -->
.demo-hover-btn:hover {
  background: linear-gradient(135deg, #6366f1, #8b5cf6);
  transform: translateY(-2px);
}
.demo-hover-btn:active {
  transform: translateY(1px);
}
.demo-focus-input:focus {
  border-color: #6366f1;
  box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.3);
}

1.2

Structural & DOM State

Target elements based on their position in the document tree (:first-child, :last-child, :nth-child(n), :not()).

Raw Code Snippets HTML & CSS 
<!-- HTML -->
<ul class="demo-struct-list">
  <li>Item 1 (:first-child)</li>
  <li>Item 2 (:nth-child even)</li>
  <li>Item 3 (:nth-child(3))</li>
  <li>Item 4 (:last-child)</li>
</ul>

<!-- CSS -->
li:first-child { color: #34d399; }
li:last-child { color: #f87171; }
li:nth-child(even) { background: rgba(59,130,246,0.1); }
p:not(.highlighted) { opacity: 0.6; }
Actual Live Output Effect (Structural Highlights)
  • 🍏 Item 1: First Child Selector :first-child
  • 🫐 Item 2: Even Row Selector :nth-child(even)
  • 🍊 Item 3: Specific Index Selector :nth-child(3)
  • 🍓 Item 4: Last Child Selector :last-child

1.3

Form States

Style input fields and buttons based on interactivity and validation criteria (:checked, :disabled, :required, :valid).

Raw Code Snippets HTML & CSS 
<!-- HTML -->
<label>
  <input type="checkbox" class="demo-checkbox">
  <span>Complete Masterclass Task</span>
</label>
<input type="email" class="demo-required-input" required placeholder="Required Email...">

<!-- CSS -->
input[type="checkbox"]:checked + span {
  color: #34d399;
  text-decoration: line-through;
}
input:required {
  border-left: 3px solid #f59e0b;
}
input:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}

Section 2

Pseudo-Elements (::)

A pseudo-element is used to style specific parts of an element, such as its first letter, line, or inserting generated decorative content before and after the element.

2.1

Generated Content

Inject decorative icons, emojis, or badges dynamically using ::before and ::after.

Raw Code Snippets HTML & CSS 
<!-- HTML -->
<span class="demo-before-after">Dynamic Decorated Text</span>
<div class="demo-badge-gen">Feature Title</div>

<!-- CSS -->
.demo-before-after::before {
  content: "✨ ";
}
.demo-before-after::after {
  content: " 🚀";
}
.demo-badge-gen::after {
  content: " NEW";
  background: #ef4444;
  color: white;
  border-radius: 9999px;
}

2.2

Typography & Selection

Style magazine drops caps, lead lines, and text highlight colors (::first-letter, ::first-line, ::selection).

Raw Code Snippets HTML & CSS 
<!-- HTML -->
<div class="demo-typography demo-selection-box">
  <p>Typography styling transforms standard paragraphs into magazine-style layouts with drop caps and highlighted lines. Try highlighting this text with your mouse!</p>
</div>

<!-- CSS -->
p::first-letter {
  font-size: 2.5rem;
  font-weight: 800;
  color: #818cf8;
  float: left;
}
.demo-selection-box::selection {
  background: #f43f5e;
  color: #ffffff;
}
Actual Live Output Effect (Select text with mouse)

Typography styling transforms standard paragraphs into magazine-style layouts with drop caps and highlighted lines. Try highlighting this text with your mouse to observe custom ::selection colors!

2.3

Forms & Placeholders

Customize input placeholder styling and file upload buttons (::placeholder, ::file-selector-button).

Raw Code Snippets HTML & CSS 
<!-- HTML -->
<input class="demo-placeholder-input" type="text" placeholder="Type something here...">
<input class="demo-file-btn" type="file">

<!-- CSS -->
input::placeholder {
  color: #64748b;
  font-style: italic;
}
input[type="file"]::file-selector-button {
  background: #4f46e5;
  color: white;
  padding: 6px 14px;
  border-radius: 6px;
}
