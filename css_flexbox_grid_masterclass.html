Module 0

Foundations of Page Layout & UX Impact

1

What is a Layout?

A layout is the spatial arrangement of visual elements on a digital canvas. It dictates how textual hierarchy, media, and interactive components relate to one another across viewports.

2

Why Layout Matters

Proper layout design establishes visual flow, guides user scanning patterns (like F-shapes and Z-patterns), minimizes cognitive load, and drives conversion goals.

3

Responsive Mechanics

Responsive design ensures fluid adaptability across devices. Modern CSS replaces brittle floats with flexible track systems and implicit wrapping rules.

CSS Flexbox (1-Dimensional Layout Engine)

Optimized for space distribution and alignment along a single axis (Row or Column).

1.1 Direction & Wrapping (`flex-direction` & `flex-wrap`)

Example 1: Row vs Column Flow
HTML / CSS
<!-- HTML --> <div class="flex-col-demo"> <div>Item 1</div> <div>Item 2</div> <div>Item 3</div> </div> /* CSS */ .flex-col-demo { display: flex; flex-direction: column; /* or row */ gap: 12px; }

/* CSS */ .wrap-demo { display: flex; flex-wrap: wrap; /* Forces items onto new lines */ gap: 12px; } .wrap-demo > div { flex: 1 1 120px; /* min-width 120px */ }

CSS Grid (2-Dimensional Layout Engine)

Controls rows and columns simultaneously for robust webpage architectures.

2.1 Tracks & Sizing Units (`fr`, `repeat`, `minmax`)

Example 1: Equal 3-Column Grid (`repeat(3, 1fr)`)
/* CSS */ .grid-3col { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; }

Example 2: Sidebar & Main Content Split
/* CSS */ .sidebar-layout { display: grid; grid-template-columns: 240px 1fr; gap: 16px; }

Example 1: Classic App Shell Layout
