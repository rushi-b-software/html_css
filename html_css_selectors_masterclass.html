Section 1

Relationship Combinators

Combinators explain the relationship between selectors. They allow you to target elements based on their hierarchical placement in the DOM tree relative to other elements.

A B Descendant Combinator (Space)

Matches all elements that are descendants of a specified element (children, grandchildren, great-grandchildren, etc.).

div span { color: #818cf8; }
Raw Code Snippet HTML & CSS 
<!-- HTML -->
<div class="box">
  <p>Direct child paragraph.</p>
  <div class="inner">
    <p>Nested grandchild paragraph.</p>
  </div>
</div>

<!-- CSS -->
.box p {
  color: #38bdf8;
  font-weight: 600;
}
Actual Output Effect

✓ Targeted: Direct child paragraph inside .box

✓ Targeted: Nested grandchild paragraph inside .inner

Notice how both paragraphs are styled because the space combinator targets all nested levels.

A > B Child Combinator (>)

Matches only elements that are direct children (first-level descendants) of a specified element.

div > p { color: #a78bfa; }
Raw Code Snippet HTML & CSS 
<!-- HTML -->
<div class="card">
  <p>Direct child (Matches style).</p>
  <div class="wrapper">
    <p>Nested grandchild (Ignored!).</p>
  </div>
</div>

<!-- CSS -->
.card > p {
  color: #a78bfa;
  font-weight: 600;
}
Actual Output Effect

✓ Targeted: Direct child paragraph

✕ Not targeted: Nested grandchild paragraph inside wrapper

Only the direct child paragraph is styled. The grandchild inside .wrapper remains default color.

A + B Adjacent Sibling (+)

Matches the second element only if it immediately follows the first element and they share the same parent.

h3 + p { color: #34d399; }
Raw Code Snippet HTML & CSS 
<!-- HTML -->
<h3>Heading Title</h3>
<p>Immediately follows h3 (Matches!).</p>
<p>Second paragraph (Ignored!).</p>

<!-- CSS -->
h3 + p {
  color: #34d399;
  font-weight: 600;
}
Actual Output Effect

Heading Title

✓ Targeted: Immediately follows h3

✕ Not targeted: Second paragraph in sequence

Only the paragraph directly succeeding the heading gets styled.

A ~ B General Sibling (~)

Matches all elements that are siblings of a specified element and appear after it in the DOM tree.

h3 ~ p { color: #fbbf24; }
Raw Code Snippet HTML & CSS 
<!-- HTML -->
<h3>Section Title</h3>
<p>First following sibling (Matches!).</p>
<div>A div container in between</div>
<p>Second following sibling (Matches too!).</p>

<!-- CSS -->
h3 ~ p {
  color: #fbbf24;
  font-weight: 600;
}
Actual Output Effect

Section Title

✓ Targeted: First following sibling

A div container in between

✓ Targeted: Second following sibling after div

All paragraph siblings appearing after the h3 are styled, even with intervening elements.

Section 2

Chaining Selectors (AND)

Chaining selectors without spaces applies styles only when an element satisfies all of the combined selector conditions simultaneously.

tag.class#id[attr] Strict Intersection (AND)

Example: button.primary.active targets only buttons that have both classes.

input.admin-input[type="text"] { ... }
Raw Code Snippet HTML & CSS 
<!-- HTML -->
<div class="card">Normal Card</div>
<div class="card featured">Featured Card (Matches both!)</div>
<p class="featured">Featured Paragraph (Ignored, not a div)</p>

<!-- CSS -->
div.card.featured {
  background-color: #4c1d95;
  border: 2px solid #a78bfa;
  color: #ffffff;
}
Actual Output Effect
Standard Card (.card only)
✓ Highlighted Card (div.card.featured)
Standard Paragraph (.featured class, but not a div)

Only the second element matches because it is strictly a <div> with both classes attached.

Section 3

Grouping Selectors (OR)

Grouping selectors using commas (,) allows you to apply the exact same block of CSS declarations to multiple distinct selectors simultaneously.

Selector1, Selector2, Selector3 Union / OR (,)

Reduces code duplication by sharing common design tokens across disparate elements.

h1, h2, .highlight-text { color: #38bdf8; }
Raw Code Snippet HTML & CSS 
<!-- HTML -->
<h1>Heading One (Shared Style)</h1>
<h2>Heading Two (Shared Style)</h2>
<span class="custom-badge">Custom Badge (Shared Style)</span>

<!-- CSS -->
h1, h2, .custom-badge {
  color: #38bdf8;
  border-left: 3px solid #38bdf8;
  padding-left: 8px;
}
Actual Output Effect

Heading One

Heading Two

Custom Badge Element

All three distinct element types successfully receive identical styling rules from one grouped block.

Mixing It All Together

Real-world frontend engineering combines combinators, chaining, pseudo-classes, and grouping to build robust, scalable component architectures.

  <div class="card-header">

    <span class="badge">Popular</span>

    <p class="price">$29</p>
    <ul>
      <li>Unlimited Projects</li>
      <li>Priority Support</li>

.pricing-card > .card-header + .card-body {
  padding-top: 12px;
}
.card-body li:first-child, .card-body li:last-child {
  color: #34d399;
