Module 0: Fundamentals of Layout & UX Impact

What is a Web Layout?

A layout is the visual architecture of a web page. It defines how digital elements (text, media, buttons, navigation) are organized relative to each other and the viewport screen size.

1. Why Layout Design Matters

  • Visual Hierarchy: Directs the user's attention to primary information and calls to action (CTAs).
  • Readability & Scannability: Structured spacing and content grouping reduce cognitive load.
  • Consistency: Establishes predictability across multiple pages and views.

2. How Layouts Elevate Web User Experience (UX)

Modern responsive layouts prevent horizontal scrollbars, preserve touch targets on mobile displays, and allow desktop browsers to take full advantage of wider viewports with structured multi-column flows.

Module 1: CSS Flexbox (1D Layout System)

Flexbox Core Concept

Flexbox operates on a **single-axis model** (either row horizontally OR column vertically). It distributes space and aligns content dynamically within a parent container.

1.1 Flex Direction & Axes

The flex-direction property defines the primary axis.

Example A: Horizontal Row Layout (Default)
.container { display: flex; flex-direction: row; gap: 10px; }

1.2 Alignment & Justification

justify-content handles spacing along the main axis, while align-items handles alignment on the cross axis.

Example A: Space Between (Navbar Pattern)

Module 2: CSS Grid (2D Layout System)

CSS Grid Core Concept

CSS Grid is a **two-dimensional layout engine**. It controls both columns and rows simultaneously, allowing precise alignment across complex multi-card layouts and page templates.

2.1 Defining Tracks with Units (fr, repeat, minmax)

Example A: Fractional Units (3 Equal Columns)
.grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; }
Col 1
Col 2
Col 3
Example B: Sidebar & Content Track Split
.dashboard { display: grid; grid-template-columns: 120px 1fr; gap: 10px; }

2.2 Template Areas (Semantic Layout)

Example: Standard App Layout with grid-template-areas
.app { display: grid; grid-template-areas: "header header" "sidebar content" "footer footer"; gap: 8px; }
